# DualClock v3.3.6


## v3.3.6 修复

1. **状态栏秒数整秒对齐**：定时器从下一整秒开始触发，不再按应用启动时刻“每隔 1 秒”滚动；每次刷新都重新读取系统当前时间，不做秒数累加。
2. **睡眠唤醒 / 系统校时自动重同步**：Mac 唤醒、系统时钟或时区发生变化时，立即刷新并重新对齐整秒。
3. **日历自动回到今天**：每天跨日时自动更新“今天”高亮；每次重新打开日历浮窗也会回到当前年月并刷新今日方块，无需再手动点“今”。
4. **“‹ 今 ›”垂直居中**：三个导航文字都按各自字体的实际绘制尺寸在按钮矩形中做水平、垂直居中，不再依赖同一个文本框顶部基线。

本版保持原有页面、尺寸、颜色、状态栏格式、双时区、日历、农历、节假日和目标功能不变；只修复“我的目标”展开/收起时 Popover 的重绘闪烁、状态栏偶发漏点，并让日历浮窗在鼠标移出后自动收起。

1. Popover 不再为高度变化播放系统动画
2. “我的目标”展开/收起只触发一次页面重绘
3. 日历页在启动时预建，第一次点击不会同步初始化
4. 状态栏按钮在鼠标按下时响应，不再依赖鼠标抬起的时机
5. 浮窗只在显示期间临时监听指针；离开浮窗和状态栏后自动关闭，关闭时立即释放监听
6. 安装包只保留一个执行脚本：`install.command`
7. 以 arm64 + `-Wall -Wextra -Werror` 编译，最低支持 macOS 13

## 角标居中修复

不再使用“向下偏移 1 pt”的经验修正。

现在直接根据当前字体和字符的实际绘制尺寸计算：

- 水平中心 = 圆心 X - 文字宽度 / 2
- 垂直中心 = 圆心 Y - 文字高度 / 2

然后使用 `drawAtPoint:` 绘制。

这比固定偏移更可靠，也不会增加常驻对象、定时器、缓存或后台逻辑。

